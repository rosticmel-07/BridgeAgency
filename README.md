# Bridge Agency

Next.js / React / TypeScript, CSS Modules. Чорно-червона стилістика з інтерактивними демонстраціями послуг. Усі CSS-файли без коментарів і порожніх рядків, з однаковим форматуванням.

## Локальний запуск

```bash
npm ci
npm run dev
```

Для production потрібен хостинг із підтримкою Next.js server routes:

```bash
npm run build
npm start
```

Статичне розміщення без сервера не підтримує `/api/contact`.

## Сторінки й умови

| URL | Послуга | Пакет |
| --- | --- | --- |
| `/services/landing` | Лендінг | $150, до 7 секцій, орієнтовно 3–5 днів |
| `/services/business-site` | Сайт компанії | Від $300, сторінки послуг + про компанію, контакти, FAQ; орієнтовно 7 днів |
| `/services/telegram-bot` | Telegram-бот | Від $80 за базовий сценарій; оплата після тестування |
| `/services/site-ads` | Сайт + реклама | Від $400, лендінг + старт кампанії та 14 днів ведення |

`/services/shop` перенаправляється на `/services/business-site`: погоджений пакет є багатосторінковим сайтом компанії, не інтернет-магазином.

Повні тексти й комплектації — `data/serviceDetails.ts`, короткі картки — `data/services.ts`, кейси — `data/PortfolioCase.ts`.
Тексти й підбір зображень входять у пакети сайтів. Реальні фото робіт, сертифікати й інші фактичні матеріали погоджуються з клієнтом. Домен, хостинг та рекламний бюджет оплачуються окремо.
Пакет реклами включає до 2 груп і 3 оголошень, допомогу з 3 простими статичними креативами, відстеження заявок і підсумковий звіт. Продовження ведення — за окремою домовленістю.

## Заявки та контакти

Скопіюйте `.env.example` у `.env.local`; на хостингу задайте серверні `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`. Не комітьте секрети та не використовуйте `NEXT_PUBLIC_` для них.
Форма показує успіх лише після підтвердження Telegram. Без конфігурації повертається чесна помилка з прямим посиланням на Telegram. Адреса `bridgee_agency` з початкового коду зберігається в `data/contact.ts`.
До заявки додаються шлях сторінки й UTM-параметри поточного URL. Вони не зберігаються між переходами без параметрів. Тип послуги автоматично вибраний на її сторінці.
Є перевірка розміру та полів запиту, honeypot і перевірка Origin; ці заходи не замінюють обмеження частоти запитів на рівні хостингу.

## Аналітика

Після підтвердженої доставки форма додає `generate_lead` із назвою послуги в `window.dataLayer`, без імені, контакту та тексту заявки. Це підготовлена подія, а не встановлена аналітика: GTM/Meta Pixel та їхні ідентифікатори ще не підключені. Перед рекламою підключіть потрібну аналітику й перевірте облік конверсій.

## Перевірки

```bash
npm run lint
npm run build
node --test tests/contact.test.mjs
```

Тести використовують імітацію Telegram API й не надсилають реальних повідомлень.

## Перед публікацією

- Підключити домен, хостинг і серверні змінні для отримання заявок.
- Перевірити власника Telegram та доставку контрольної заявки.
- Підключити й перевірити аналітику для реклами.
- За можливості додати публічні URL і реальні скриншоти кейсів: зараз у головному портфоліо схематичні прев’ю, а демонстрації на сторінках послуг позначені як інтерактивні приклади.
- Близько 100 звернень у кейсі композитної сітки — інформація власника; це не кількість продажів і не гарантія результату іншого проєкту.
- Безкоштовний аудит за 24 години не заявлений, оскільки його умови не затверджені.
